# Blanche Francheterre

Source of my personal website, https://blanchefrancheterre.github.io, built with [al-folio](https://github.com/alshedivat/al-folio).

## Where to edit

| What                  | File                                    |
| --------------------- | --------------------------------------- |
| Name, site settings   | `_config.yml`                           |
| Home page / biography | `_pages/about.md`                       |
| Social links          | `_data/socials.yml`                     |
| Publications          | `_bibliography/papers.bib`              |
| CV                    | `_data/cv.yml`                          |
| Projects              | `_projects/` (copy `1_project.md`)      |
| Photos and PDFs       | `assets/img/`, `assets/pdf/`            |

Pushing to `main` rebuilds the site via the `Deploy site` GitHub Action. See `docs/` for the full al-folio documentation.
